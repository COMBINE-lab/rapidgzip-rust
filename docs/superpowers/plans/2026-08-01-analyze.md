# DEFLATE Analysis Implementation Plan

> Execution checklist for `docs/superpowers/specs/2026-08-01-analyze-design.md`. Boxes are ticked as each step lands, one commit per step.

**Goal:** Walk every DEFLATE block, expose the result as data, and print rapidgzip 0.16.0's exact report.

**Branch:** `analyze`, stacked on `cli-parity` (PR #11).

## Reuse

`parallel/deflate.rs` already has `BitReader`, `Huffman`, the length and
distance tables, and dynamic-header parsing. The analyzer needs the same
parsing plus the code-length vectors that parsing discards, so those items
become `pub(crate)` and gain a variant returning the vectors. It keeps its own
decode loop, because it counts symbol kinds and back-reference distances rather
than producing markers.

Header fields are parsed by the analyzer rather than by `parse_member_header`,
which deliberately keeps only the offsets the decoder needs.

## Steps

- [x] **1. Block walker and the `Analysis` type**
  `analyze.rs` in the core library, with `Decoder::analyze` returning a public
  `Analysis`: per stream the container, header fields, offsets, footer; per
  block the type, offsets in bits, sizes, the three code-length count maps,
  symbol-kind counts, farthest back-reference, and the window-usage counts.
  Verify: block sizes sum to the total, offsets increase, the last block of
  each stream is final, on gzip, multi-member, BGZF, stored, fixed-Huffman,
  zlib, and raw DEFLATE corpora.

- [x] **2. Formatting primitives**
  `analyze_format.rs` in the CLI: C++ `%.6g` and `%.6e` reproduction,
  `formatBits`, `formatBytes`, and the histogram with its bucketing and bar
  rules.
  Verify: unit tests at zero, at unit boundaries, when all values are equal,
  when the range is smaller than the bin count, and at the `max` boundary.

- [ ] **3. The report**
  `--analyze` printing every section in rapidgzip's order, with the benchmark
  profile carrying our own measured durations.

- [ ] **4. Differential test and CI**
  `tests/analyze_interop.rs`, ignored by default, diffing against real
  `rapidgzip --analyze` with the duration lines masked. The interop CI job
  installs `rapidgzip==0.16.0`.

- [ ] **5. Documentation**
  `README.md`, `ARCHITECTURE.md`, `CHANGELOG.md`, and the crate docs, stating
  plainly which section cannot match and why.

## Global constraints

- MSRV 1.87, Rust 2024, no let-chains, no new dependencies.
- `cargo fmt --check`, `cargo clippy --workspace --all-targets -- -D warnings`,
  and the full suite pass before each commit.
- No em dashes. Commits end with the Claude co-author trailer.
